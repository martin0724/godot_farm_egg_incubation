## 1. 游戏概念（一句话）

老师用一台电脑 + 投影，把整个教室变成一个「超级农场」。屏幕上每个小朋友对应一只**母鸡 + 一个鸡窝 + 5 颗蛋**。孩子坐好即可让蛋自动孵化；一旦离座/吵闹，老师在后台点一下，屏幕上就会有一只**小老鼠跑出来偷蛋**；表现好的孩子老师点一下，**农场主人来投喂，孵蛋加速**。整节课结束按孵化成果排名。

---

## 2. 游戏目标与胜负

### 2.1 单个玩家的目标
- 在整节课时间内，把自己初始的 **5 颗蛋全部孵化成 5 只小鸡**。
- 避免蛋被老鼠偷光。

### 2.2 玩家（鸡窝）状态定义

| 状态 | 枚举值 | 说明 |
| --- | --- | --- |
| 正常孵蛋中 | `NORMAL` | 孵化进度自动增长 |
| 母鸡离窝 | `HEN_LEFT` | 惩罚触发瞬间状态，蛋停止孵化并在短暂动画后可能被偷 |
| 孵蛋暂停 | `PAUSED` | 轻微分心，进度冻结，蛋不会被偷 |
| 鸡窝破损/失败 | `FAILED` | 5 颗蛋被偷光，本轮出局（本课内） |
| 通关 | `COMPLETED` | 5 颗蛋全部孵化为小鸡 |

### 2.3 全局状态

| 全局状态 | 枚举值 | 说明 |
| --- | --- | --- |
| 故事导入 | `INTRO` | 播放开场话术，主循环未开始 |
| 游戏进行中 | `PLAYING` | 孵蛋计时器运行，可控奖惩 |
| 结算画面 | `ENDED` | 展示排名榜 |

### 2.4 结算排名规则（对应 game.md 第五节）
1. **农场金牌母鸡**：最先孵满 5 只小鸡（`incubated_chicks == 5` 中时间最早者）。
2. **优秀孵蛋小能手**：未通关但保住的蛋数（`eggs + incubated_chicks`）排名靠前者。
3. **需要努力**：蛋被偷光（`FAILED`）的玩家。

## 3. 核心数值设计（可调参数，集中在一个配置资源中）

> 所有数值应放在一个 `GameConfig` 资源或常量脚本中，方便老师/开发调整。

```
# 建议命名：res://scripts/game_config.gd (class_name GameConfig)
INITIAL_EGGS            = 5          # 每人初始鸡蛋数
TOTAL_CHICKS_TO_WIN     = 5          # 通关所需小鸡数

# 孵蛋节奏（分钟）——老师二选一
MODE_A_SECONDS_PER_EGG  = 5 * 60     # 模式 A：5 分钟 1 颗蛋
MODE_B_SECONDS_PER_EGG  = 8 * 60     # 模式 B：8 分钟 1 颗蛋

# 惩罚数值
EGG_STEAL_ON_LEAVE      = 1          # 离座偷 1 颗
EGG_STEAL_ON_NOISE      = 2          # 吵闹偷袭偷 2 颗
DISTRACTION_PAUSE_SEC   = 10.0       # 轻微分心暂停孵蛋的时长（可选，默认手动恢复）

# 奖励数值
FEED_SPEED_BUFF_MULT    = 2.0        # 投喂加速倍率
FEED_BUFF_DURATION_SEC  = 30.0       # 加速持续时间
SHIELD_DURATION_SEC     = 60.0       # 保护盾持续时间（期间免疫被偷蛋）
ANSWER_INSTANT_EGGS     = 1          # 举手答题直接孵化 1 颗蛋
```

**说明**：
- 「孵蛋进度」以 `0.0 → 1.0` 表示一颗蛋的孵化程度，达到 1.0 时 `eggs -= 1`、`incubated_chicks += 1`，进度归零开始下一颗。
- 加速 buff 生效时：`progress += delta / SECONDS_PER_EGG * FEED_SPEED_BUFF_MULT`。
- 保护盾生效时：任何「偷蛋」惩罚对该作者无效，播放「盾弹开老鼠」的动画。

## 4. 数据结构规格

### 4.1 `PlayerState`（每个鸡窝 / 每个孩子）

建议实现为 `Resource`（可 `class_name PlayerState`），便于序列化与结算。

```
class_name PlayerState extends Resource

@export var id: int = 0
@export var display_name: String = "小鸡窝"        # 显示名，默认"1号鸡窝"
@export var eggs: int = 5                           # 剩余鸡蛋数
@export var chicks: int = 0                         # 已孵出小鸡数
@export var hatch_progress: float = 0.0             # 当前蛋孵化进度 [0.0,1.0]
@export var shield_seconds: float = 0.0             # 保护盾剩余时间
@export var buff_seconds: float = 0.0               # 加速 buff 剩余时间
@export var shield_active: bool = false
@export var buff_active: bool = false
@export var status: PlayerStatus = PlayerStatus.NORMAL
@export var completed_at_time: float = -1.0         # 通关时刻（用于排名），-1 表示未通关

enum PlayerStatus { NORMAL, HEN_LEFT, PAUSED, FAILED, COMPLETED }

# 派生属性
func total_survived() -> int:
    return eggs + chicks
```

### 4.2 `GameConfig`（数值 + 模式）

```
class_name GameConfig extends Resource

enum Mode { MODE_A, MODE_B }

@export var mode: Mode = Mode.MODE_A
@export var player_count: int = 20

# 其余常量见第 3 节
func seconds_per_egg() -> float:
    return 300.0 if mode == Mode.MODE_A else 480.0
```

### 4.3 全局管理器（Autoload 单例）`GameManager`

负责：持有玩家列表、全局状态、计时、派发信号、结算。

```
# res://autoload/game_manager.gd  (Autoload 名称: GameManager)
extends Node

signal state_changed(new_state: int)
signal player_updated(player: PlayerState)
signal egg_stolen(player_id: int, amount: int, noise_level: bool)
signal egg_hatched(player_id: int)
signal hen_left_nest(player_id: int)
signal hen_returned(player_id: int)
signal mouse_appeared(player_id: int)
signal reward_fed(player_id: int, buff: bool, shield: bool)
signal shield_activated(player_id: int)
signal shield_blocked(player_id: int)
signal nest_destroyed(player_id: int)
signal player_completed(player_id: int)
signal game_ended(ranking: Array)

var config: GameConfig
var players: Array[PlayerState] = []
var current_state: int = State.INTRO
var elapsed_time: float = 0.0
var winner_id: int = -1

enum State { INTRO, PLAYING, ENDED }
```

**关键方法（AI 需实现的接口）：**

| 方法 | 作用 |
| --- | --- |
| `start_game(mode, player_count)` | 创建玩家列表，状态切到 `PLAYING`，开始计时 |
| `_process(delta)` | 推进每个正常玩家的孵化进度、衰减 buff/shield 计时 |
| `trigger_leave(player_id)` | 离座惩罚：母鸡离窝动画 → 老鼠偷 1 蛋 |
| `trigger_noise(player_id)` | 吵闹惩罚：老鼠大偷袭偷 2 蛋 |
| `trigger_distraction(player_id)` | 轻微分心：状态置 `PAUSED`，孵蛋暂停 |
| `resume_player(player_id)` | 恢复 `PAUSED` → `NORMAL` |
| `trigger_feed(player_id)` | 投喂：随机给「加速 buff」或「保护盾」 |
| `trigger_answer(player_id)` | 答题：直接推进孵化 1 颗蛋 |
| `trigger_shield(player_id)` | 直接给保护盾 |
| `end_game()` | 状态切 `ENDED`，计算 ranking 并发射 `game_ended` |
| `get_ranking() -> Array` | 返回排序后的排名数据 |

## 5. 核心逻辑伪代码（供 AI 直接转译为 GDScript）

### 5.1 每帧主循环 `_process(delta)`

```
if current_state != PLAYING: return
elapsed_time += delta
for p in players:
    if p.status == NORMAL and p.eggs > 0:
        var mult = FEED_SPEED_BUFF_MULT if p.buff_active else 1.0
        p.hatch_progress += delta / config.seconds_per_egg() * mult
        if p.hatch_progress >= 1.0:
            hatch_one_egg(p)      # eggs -=1; chicks +=1; progress=0; 发 egg_hatched
    # 衰减计时器
    if p.shield_seconds > 0: p.shield_seconds -= delta; p.shield_active = p.shield_seconds > 0
    if p.buff_seconds   > 0: p.buff_seconds   -= delta; p.buff_active   = p.buff_seconds   > 0
    emit_signal("player_updated", p)
```

### 5.2 偷蛋逻辑（被离座 / 吵闹共用）

```
func steal_eggs(p, amount):
    if p.status == FAILED or p.status == COMPLETED: return
    if p.shield_active:
        emit shield_blocked(p.id)     # 盾弹开老鼠，不偷
        return
    p.eggs = max(0, p.eggs - amount)
    emit egg_stolen(p.id, amount, noise_level)
    if p.eggs <= 0 and p.chicks == 0 ... 或 eggs<=0:
        p.status = FAILED
        emit nest_destroyed(p.id)
```

> **注意**：`game.md` 原文写「蛋全部被偷完 → 失败」。是否将「已孵出的小鸡」也算作成果需与老师确认；**默认规则：只要剩余蛋为 0 且未通关即视为失败**（详见第 11 节待确认项）。

### 5.3 通关判定

```
func hatch_one_egg(p):
    p.eggs -= 1
    p.chicks += 1
    p.hatch_progress = 0.0
    emit egg_hatched(p.id)
    if p.chicks >= TOTAL_CHICKS_TO_WIN:
        p.status = COMPLETED
        p.completed_at_time = elapsed_time
        if winner_id == -1: winner_id = p.id
        emit player_completed(p.id)
```

### 5.4 结算排名

```
func get_ranking() -> Array:
    # 1) 通关者按完成时间升序
    var completed = players.filter(f(completed)).sorted(completed_at_time)
    # 2) 未通关者按存活数 (eggs+chicks) 降序
    var others = players.filter(not completed).sorted(total_survived desc)
    # 标记头衔
    # completed[0] -> "农场金牌母鸡"
    # 其余 completed + others 中 survived 高者 -> "优秀孵蛋小能手"
    # FAILED -> "需要下节课继续努力"
```

## 7. 教师控制台（TeacherPanel）交互设计

> 一切奖惩由老师触发。为了上课方便，提供 **两套等价操作**：鼠标点击 + 键盘快捷键。

### 7.1 操作流程
1. 老师先用鼠标**点击选中某个鸡窝**（高亮边框）。
2. 再点击下方功能按钮，或按快捷键，对该鸡窝生效。

### 7.2 功能按钮 / 快捷键映射

| 功能 | 快捷键 | 对应方法 | 效果 |
| --- | --- | --- | --- |
| 离座（老鼠偷 1） | `Q` | `trigger_leave(id)` | 母鸡离窝 → 老鼠偷 1 蛋 |
| 吵闹（老鼠偷 2） | `W` | `trigger_noise(id)` | 老鼠偷袭偷 2 蛋 |
| 轻微分心（暂停） | `E` | `trigger_distraction(id)` | 孵蛋暂停 |
| 恢复 | `R` | `resume_player(id)` | 解除暂停 |
| 投喂奖励 | `A` | `trigger_feed(id)` | 随机 buff / 盾 |
| 答题奖励 | `S` | `trigger_answer(id)` | 立即孵化 1 蛋 |
| 全员投喂 | `Shift+A` | 对所有 `NORMAL` 玩家 `trigger_feed` | 全班奖励 |
| 开始/结束本课 | `Space` / `Esc` | `start_game` / `end_game` | 全局状态切换 |

### 7.3 面板显隐
- 默认按 `Tab` 切换控制台的显示/隐藏，避免孩子看到。
- 教师面板不要遮挡鸡窝区（放在屏幕底部条或侧边抽屉）。

## 10. UI 设计细节

### 10.1 TopBar（顶栏）
- 左：当前模式（A / B）、已进行时间（mm:ss）
- 中：标题「超级农场·孵蛋大作战」
- 右：已通关人数 / 总人数；老师「开始 / 结束」按钮

### 10.2 IntroOverlay（开场）
- 全屏故事卡片，展示开场话术文字（可配插画），底部按钮「开始上课」。

### 10.3 ResultOverlay（结算榜）
- 三档头衔分区展示（金牌母鸡 / 优秀孵蛋小能手 / 继续努力）
- 每项显示：编号、剩余蛋、小鸡数、完成时间
- 底部按钮：「再来一节课」（重置）、「关闭」

### 10.4 NestSlot 状态可视化
- 5 个蛋槽：有蛋 = 蛋图标，无蛋 = 空槽；孵化中 = 当前槽显示进度环。
- 小鸡行：每孵出一只，添加一个小鸡图标。
- 角标颜色：暂停 = 黄，失败 = 红，通关 = 金。

### 10.5 布局适配
- 支持 10–25 人：根据人数自动计算网格列数（如 5×2 到 5×5），`NestSlot` 自适应缩放。
- 使用 `GridContainer` 或自定义 flow 布局，保证 16:9 投影不溢出。

## 11. 待确认 / 开放问题（编码前需与策划确认）

1. **失败判定**：剩蛋为 0 是否立即失败？已孵化的小鸡是否算「保住」？（默认：蛋 = 0 且未通关 → `FAILED`，但小鸡数仍计入结算展示）
2. **暂停能否自动恢复**：轻微分心由老师手动恢复，还是 N 秒后自动恢复？（默认手动）
3. **离座后是否有「回窝」动作**：偷蛋后母鸡是否自动回窝继续孵化？（默认：偷蛋动画结束后自动回 `NORMAL`）
4. **奖励随机性**：投喂是随机给 buff / 盾，还是老师指定？（默认随机 50/50，另保留手动 `trigger_shield`）
5. **存档需求**：是否需要保存每节课历史成绩？（默认不保存，仅内存）
6. **人数上限**：25 人以上是否支持？（默认支持到 30，超出走滚动布局）

## 12. 开发里程碑（建议实现顺序）

### 15.1 `autoload/game_manager.gd`（核心节选）

```gdscript
extends Node

signal player_updated(player)
signal egg_stolen(player_id, amount)
signal egg_hatched(player_id)
signal mouse_appeared(player_id)
signal reward_fed(player_id, kind)
signal shield_blocked(player_id)
signal nest_destroyed(player_id)
signal player_completed(player_id)
signal game_ended(ranking)

enum State { INTRO, PLAYING, ENDED }

var config := GameConfig.new()
var players: Array = []
var current_state: int = State.INTRO
var elapsed_time := 0.0
var winner_id := -1

func start_game(mode: int, count: int) -> void:
    config.mode = mode
    players.clear()
    for i in count:
        var p := PlayerState.new()
        p.id = i
        p.display_name = "%d号鸡窝" % (i + 1)
        p.eggs = GameConfig.INITIAL_EGGS
        players.append(p)
    elapsed_time = 0.0
    winner_id = -1
    current_state = State.PLAYING

func _process(delta: float) -> void:
    if current_state != State.PLAYING:
        return
    elapsed_time += delta
    for p in players:
        _tick_player(p, delta)

func _tick_player(p, delta: float) -> void:
    if p.shield_seconds > 0.0:
        p.shield_seconds -= delta
        p.shield_active = p.shield_seconds > 0.0
    if p.buff_seconds > 0.0:
        p.buff_seconds -= delta
        p.buff_active = p.buff_seconds > 0.0
    if p.status == PlayerState.PlayerStatus.NORMAL and p.eggs > 0:
        var mult := GameConfig.FEED_SPEED_BUFF_MULT if p.buff_active else 1.0
        p.hatch_progress += delta / config.seconds_per_egg() * mult
        if p.hatch_progress >= 1.0:
            _hatch_one(p)
    player_updated.emit(p)

func _hatch_one(p) -> void:
    p.eggs -= 1
    p.chicks += 1
    p.hatch_progress = 0.0
    egg_hatched.emit(p.id)
    if p.chicks >= GameConfig.TOTAL_CHICKS_TO_WIN:
        p.status = PlayerState.PlayerStatus.COMPLETED
        p.completed_at_time = elapsed_time
        if winner_id == -1:
            winner_id = p.id
        player_completed.emit(p.id)

func trigger_leave(player_id: int) -> void:
    var p = players[player_id]
    p.status = PlayerState.PlayerStatus.HEN_LEFT
    mouse_appeared.emit(p.id)
    _steal(p, GameConfig.EGG_STEAL_ON_LEAVE)
    if p.status == PlayerState.PlayerStatus.HEN_LEFT:
        p.status = PlayerState.PlayerStatus.NORMAL

func trigger_noise(player_id: int) -> void:
    var p = players[player_id]
    mouse_appeared.emit(p.id)
    _steal(p, GameConfig.EGG_STEAL_ON_NOISE)

func _steal(p, amount: int) -> void:
    if p.status == PlayerState.PlayerStatus.FAILED \
            or p.status == PlayerState.PlayerStatus.COMPLETED:
        return
    if p.shield_active:
        shield_blocked.emit(p.id)
        return
    p.eggs = max(0, p.eggs - amount)
    egg_stolen.emit(p.id, amount)
    if p.eggs <= 0:
        p.status = PlayerState.PlayerStatus.FAILED
        nest_destroyed.emit(p.id)

func trigger_feed(player_id: int) -> void:
    var p = players[player_id]
    if randi() % 2 == 0:
        p.buff_seconds = GameConfig.FEED_BUFF_DURATION_SEC
        p.buff_active = true
        reward_fed.emit(p.id, "buff")
    else:
        trigger_shield(player_id)

func trigger_shield(player_id: int) -> void:
    var p = players[player_id]
    p.shield_seconds = GameConfig.SHIELD_DURATION_SEC
    p.shield_active = true
    reward_fed.emit(p.id, "shield")
```

### 15.2 `scripts/game_config.gd`（数值常量 + 模式）

```gdscript
class_name GameConfig
extends Resource

enum Mode { MODE_A, MODE_B }

const INITIAL_EGGS           := 5
const TOTAL_CHICKS_TO_WIN    := 5
const MODE_A_SECONDS_PER_EGG := 300.0
const MODE_B_SECONDS_PER_EGG := 480.0

const EGG_STEAL_ON_LEAVE     := 1
const EGG_STEAL_ON_NOISE     := 2
const FEED_SPEED_BUFF_MULT   := 2.0
const FEED_BUFF_DURATION_SEC := 30.0
const SHIELD_DURATION_SEC    := 60.0
const ANSWER_INSTANT_EGGS    := 1

@export var mode: Mode = Mode.MODE_A

func seconds_per_egg() -> float:
    return MODE_A_SECONDS_PER_EGG if mode == Mode.MODE_A else MODE_B_SECONDS_PER_EGG
```
